# 本地 SQLite 持久化

用户确认采用 SQLite，以避免清理浏览器数据导致历史和观察记录丢失。复用现有 Node 服务；单用户、同机共享，不新增登录或远程同步。

数据库默认位于 `~/.lucky-picker/data.sqlite`，支持 `LUCKY_PICKER_DATA_DIR` 指定目录。Node 内置 SQLite 保存历史、股票观察、彩票观察的版本化 JSON 文档，事务提交，修订号用于阻止过期页面覆盖。开发、预览和生产共用接口。前端启动先读数据库，成功后挂载；不可用时展示重试，保存失败不提示成功。

浏览器旧数据启动时自动合并，历史按 id、股票按 id、彩票按 key 去重，冲突保留数据库记录。整个导入事务化，导入指纹及逐条迁移登记确保旧浏览器数据不会在删除后重复复活。原浏览器数据不删除，损坏的迁移数据明确提示且不覆盖数据库。历史保留最近 50 条，观察最多各 1000 条。

提供 JSON 导出和合并导入，校验格式和数据结构，失败不部分写入。备份同时包含三类数据，不包含可重新获取的热门股缓存。接口仅本地同源使用，写请求要求 JSON 和同源 Origin，禁止跨站访问和缓存。

验证覆盖磁盘重开、事务导入、重复迁移、冲突、损坏数据、HTTP 限制、前端请求失败、现有测试与构建，以及页面实际保存和恢复。
