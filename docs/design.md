# lucky-picker 实现规格

## 目标与位置
在 `/Users/yanqiu/Code/lucky-picker` 创建 Vue 3 + TypeScript + Vite 纯前端项目，适配手机和电脑。沿用「设计选号网页」会话中确认的功能；同一个项目之后可上传 GitHub，并可部署到 GitHub Pages。本次不创建远程仓库、不发布网站。

## 幸运选号
- 双色球：红球 01–33 选 6，蓝球 01–16 选 1。
- 超级大乐透：前区 01–35 选 5，后区 01–12 选 2。
- 排列三、排列五：分别生成 3 位、5 位 0–9 数字，允许不同位置出现相同数字。
- 一次生成 1 组或 10 组；支持复制单组、复制全部、重新生成单组。
- 双色球、大乐透的各区内号码不重复且升序排列；10 组之间避免完全相同的组合。
- 使用浏览器加密随机源与拒绝采样，避免取模偏差。

## 幸运选股
从随项目提供的 A 股股票池中等概率随机选取一只，展示代码、名称、市场与股票池更新日期。股票池明确注明覆盖范围和数据来源；如使用有限样本，明确显示“精选股票池”，不声称覆盖全部 A 股。不请求行情，不提供价格或买入建议。数据过期不影响随机功能，但页面保留日期提示。支持再次随机和复制结果。

## 页面与交互
采用米白背景、深色文字、红蓝号码球和圆角卡片。顶部切换“幸运选号 / 幸运选股”；选号页提供四个彩种选项、规则说明、生成按钮、结果列表和最近记录。手机端按钮易于点击、号码列表不产生横向滚动。提供键盘焦点和按钮可访问名称，尊重减少动画偏好。

## 数据与异常
最近 50 次生成操作保存在当前浏览器 localStorage，含时间、类别和结果，支持清空。解析损坏数据时恢复为空；存储不可用时保留当次操作并提示无法保存。剪贴板不可用时展示可手动复制的文本。无账号、无后端。

## 工程结构
`src/lib` 管理随机算法与彩种规则，`src/data` 存放股票池，Vue 组件负责交互和展示。提供 README、.gitignore、锁文件和 GitHub Pages 工作流。Vite 使用适合项目路径部署的 base 配置。首次提交前不覆盖任何已有同名目录。

## 验收
验证各彩种数量、范围、区内去重和排序、排列数字允许重复；验证 10 组生成、随机股票来自声明的池。TypeScript 检查与生产构建通过。在浏览器检查切换、复制、历史持久化、重新生成和手机布局。页面注明“随机选号不提高中奖概率”和“随机选股仅供娱乐”。
